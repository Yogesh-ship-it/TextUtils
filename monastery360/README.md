# Monastery360 – Sikkim Monasteries Digital Heritage

A React + TypeScript web app scaffold to digitize and showcase Sikkim's monasteries with virtual tours, narrated walkthroughs, and an interactive map.

## Features
- Virtual Tours (placeholder): 360° viewer slot ready
- Narrated walkthroughs (placeholder): multi-language
- Interactive Map (placeholder): routes and nearby attractions
- Front (Home) and Landing pages with routing

## Getting Started

### Prerequisites
- Node.js 18+ and npm

### Install
```bash
npm install
```

### Run Dev Server
```bash
npm run dev
```
Open the URL printed in the terminal.

### Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
